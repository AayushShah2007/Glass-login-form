# Modular Glass Login Form

A sleek, glassmorphism-style login form built with pure HTML and CSS.

## Features

- Glassmorphism UI with backdrop blur
- Custom-styled input fields with icons
- "Remember me" checkbox
- Google and Facebook login buttons
- Responsive, centered layout

## Preview

The form includes username and password fields, a submit button, and social login options — all styled with a frosted glass effect over a wallpaper background.
